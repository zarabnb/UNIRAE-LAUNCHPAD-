# UNIRAE V2.17 verification record

## Checks completed in this environment

- EVM-only static guard (including repository scan for retired ecosystem references).
- Frontend inline JavaScript syntax checks using Node.js.
- Runtime smoke test of testnet/mainnet network-mode selection and chain IDs.
- Backend configuration TypeScript check using global TypeScript and a minimal ambient declaration for `dotenv/config`.
- JSON parsing for backend package metadata and Vercel configuration.
- Source and deployment archive integrity checks (performed at packaging).

## Changes

- Added explicit mainnet chain configuration entries for Ethereum (1), BNB Smart Chain (56), Robinhood Chain (4663) and X Layer (196); testnet entries remain available.
- Added runtime frontend network-mode selection; testnet remains the safe default and mainnet requires explicit configuration injection.
- Graduation migration now creates and registers the AMM pair before seeding liquidity, and the token automatically exempts the coordinator for initial liquidity.
- Migration coordinator validates dependencies, rejects pre-created pairs and accepts router refunds only from the configured router.
- Factory refuses launches until the fee vault is configured; buyback allocations require an initialized executor.
- Added fee distribution, buyback execution and migration tax-setup tests.
- Frontend now verifies deployed fee-vault code, platform recipient and buyback executor before submitting a launch.

## Not verified / not certified

- Foundry is unavailable, so Solidity compilation and runtime tests were not run.
- Backend dependencies could not be installed because package installation timed out; full Vitest, Prisma and backend build gates were not run.
- No RPC endpoints, Chainlink feeds, routers, factories, fee vaults or deployed contracts were supplied for live testnet validation.
- No end-to-end wallet transactions, DEX migration, LP lock, reorg recovery or independent security audit was performed.
- Mainnet factory, feed, router, wrapped-native and fee-vault addresses remain unset.
- Authorized equity registry remains an issuer-authorization gate, not a complete regulated issuance, custody, redemption or trading system.

**Release status: development build; not production-certified.**
