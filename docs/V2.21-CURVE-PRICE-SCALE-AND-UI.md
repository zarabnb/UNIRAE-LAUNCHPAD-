# UNIRAE V2.21 — Bonding-curve unit correction and Launch Studio

## Critical V2.20 accounting defects corrected

The V2.20 curve had inconsistent 1e18 units in three places. The factory multiplied the initial per-token price numerator by `1e36` instead of `1e18`, overstating the price by 1e18. The curve then converted native value to whole coins before USD conversion, truncating every fractional native coin (including the initial $500 FDV). Finally, buy/sell area integration divided by an extra 1e18, making quotes materially too small or zero.

V2.21 uses consistent units:

- `initialPriceX18 = ceil(initialMarketCapUsdE8 * 1e18 / (supplyWholeTokens * nativeUsdE8))`; this value is wei per whole token.
- `currentPriceWei()` returns that wei-per-token value directly.
- USD FDV first calculates native wei as `priceWeiPerToken * totalSupplyRaw / 1e18`, then converts to USD-E8 using the native/USD feed and another 1e18 divisor. Fractional native value is preserved.
- Curve integration returns native wei: linear term divides by `1e18`; quadratic term divides by `2 * 1e36`.
- 512-bit `mulDiv` is used for the large intermediate products; explicit round-up is applied to the initial price and slope.

Regression assertions now cover the exact initial wei/token price, initial $500 FDV, a nonzero one-token native-wei quote, and the $20,000 FDV graduation threshold at full curve inventory.

## UI improvements

- Persistent token watchlist stored locally in the browser.
- Watchlist filter alongside trending/top/new.
- Live Launch Studio checklist for network, metadata, supply, creator wallet and tax allocation.
- Checklist distinguishes form completeness from configured factory/oracle readiness; it does not claim an audit or live deployment.
- Keyboard shortcuts: `/` focuses discovery search; `C` opens token creation when not typing in a field.

## Verification limits

Static and syntax checks can validate source shape only. Foundry runtime tests, complete backend tests, RPC/testnet deployments, external security review and mainnet verification are still required. Do not accept production funds until all release gates pass.
