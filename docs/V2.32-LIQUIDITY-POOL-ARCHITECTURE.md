# V2.32 — Liquidity-pool architecture clarification

## What UNIRAE uses today

The Solidity graduation path is a **Uniswap V2-compatible constant-product AMM**. `UniraeV2MigrationCoordinator` calls the configured router's `factory()`, `WETH()` and `addLiquidityETH()` methods. It creates the token/wrapped-native pair, seeds it atomically during graduation, registers the pair with the token, and transfers the resulting LP tokens to `UniraeLpLocker`.

This is a router interface, not a hard-coded DEX brand. The source does not currently select or hard-code Uniswap, PancakeSwap, or another named venue. The actual venue is whichever chain-specific router is passed to the coordinator at deployment. No production router addresses are currently verified/configured in the checked-in environment templates.

## BNB first

For the planned BNB Chain Testnet end-to-end test, select a verified PancakeSwap-V2-compatible router (or another verified V2-compatible router on that testnet) and confirm its `factory()` and `WETH()` responses, pair creation behavior, fee-on-transfer compatibility, and add-liquidity behavior on chain 97. Do not copy mainnet router addresses to testnet. The deployment must fail closed if the configured router/factory/wrapped-native combination is not verified.

## V2 versus V3

The backend separately supports indexing manually registered Uniswap-V3-style pools. `UNISWAP_V3_FACTORY_*` is for V3 pool verification/indexing; it is **not** the graduation router and does not make graduation use V3 concentrated liquidity.

## Configuration

`DEX_V2_ROUTER_<NETWORK>` has been added as an explicit environment setting and exposed in backend chain configuration. Keep it blank until the exact router is verified for that chain. `WRAPPED_NATIVE_*` and `UNISWAP_V3_FACTORY_*` remain separate settings.

## Release status

No live LP venue is active merely because this interface exists. Actual migration remains dependent on deployment-time router selection, on-chain verification, Solidity compilation/runtime tests, and testnet E2E validation.
