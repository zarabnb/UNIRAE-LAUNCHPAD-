# UNIRAE V2.1 — indexer hardening

## Changes
- Reorg replay now starts one block before the stored cursor tip and places the cursor immediately before the replay window.
- Factory rollback removes orphaned launch Token records and their dependent Trade and Transfer rows before replaying canonical factory logs.
- Curve rollback removes affected curve trades and raw events.
- Trade pagination reports a total count; token detail metrics now report total indexed trades rather than only the latest 20 rows.
- Added unit tests for replay-window boundaries.

## Boundaries
This is bounded per-cursor recovery. It does not detect arbitrary deep reorganizations if the stored tip hash remains canonical, nor does it reconcile every downstream cache. Keep confirmation depth configured conservatively and monitor cursor health. No deployment, live RPC test, database migration, compiler run, or security audit is claimed by this milestone.
