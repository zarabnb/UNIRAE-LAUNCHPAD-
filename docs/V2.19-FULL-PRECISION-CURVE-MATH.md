# UNIRAE V2.19 — Full-precision curve arithmetic

Added `UniraeFullMath.mulDiv`, using a 512-bit intermediate product and exact floor division. The bonding curve uses it for integral pricing, trade-fee calculation, and USD market-cap conversion. This avoids false reverts caused by intermediate multiplication overflow when the final quotient is representable.

Regression coverage in `contract-tests/UniraeFullMath.t.sol` checks exact division, floor rounding, a 512-bit intermediate, overflow rejection, and zero-denominator rejection.

This does not change the curve formula, fee rates, supply, or graduation target. It does not establish that every possible factory configuration is economically safe. Foundry execution, fuzz/invariant testing, backend checks, live testnet verification, and independent audit remain release requirements.
