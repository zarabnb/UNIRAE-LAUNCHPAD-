## Solidity/product gaps requiring explicit implementation and tests

- Token-level buyback allocation remains disabled by the token contract (`buybackShareBps == 0`); the separate native-asset curve-fee vault buyback path is distinct and must not be represented as token-tax buyback.
- The equity registry stores owner-entered authorization evidence and expiry; it does not independently verify an issuer, custodian, transfer agent, licensing, or jurisdictional eligibility. Equity pairing must remain disabled until those checks and compliant execution routes exist.
- Graduation depends on the configured native/USD oracle and a correctly configured chain-specific router/factory/wrapped-native address. Static config shape validation does not establish that those dependencies are authentic or operational.
- A full external audit and live testnet lifecycle test remain mandatory before accepting real funds.
