# UNIRAE V2.24 — Launchpad architecture refresh

## UI changes
- Removed Airdrop from the mobile navigation and replaced it with Portfolio.
- Reorganized the launchpad around a compact hero, protocol parameters, market timeframe controls, launch-status filters, network filters, and token discovery.
- Replaced the previous crowded header with a compact launchpad navigation, network indicators, search, docs, wallet connection, and menu.
- Moved the brand mark out of the main navigation; retained a small brand signature in the footer.
- Replaced the purple visual system with a restrained charcoal/black and green palette, compact typography, square-edged controls, and clearer spacing.
- Added active-state interactions to timeframe and launch-status controls. Token entries remain explicitly labelled preview data; these controls do not claim live market filtering.

## Architecture reference
The layout follows the information hierarchy visible on Ansem's launch page: launchpad introduction, protocol metrics, trending/timeframe controls, category/status filters, network filters, token grid/table discovery, and protocol information. UNIRAE retains its own branding and EVM-only product scope.

## Validation
This is a frontend layout/interaction refresh. It does not validate live market data, wallet connection reliability, smart contracts, or testnet execution.
