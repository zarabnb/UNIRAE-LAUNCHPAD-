## Important product/security gaps remain

- Token-tax buyback allocation is still disabled in `UniraeTokenV11`; the native-asset fee-vault buyback is a separate mechanism.
- The equity registry is an evidence/expiry registry, not a full issuer, custodian, licensing or jurisdictional compliance verification system. Equity trading must remain unavailable until those controls and compliant execution routes exist.
- Oracle, router, factory and wrapped-native configuration must be verified against each target chain before graduation can be enabled.
- Static checks are not a substitute for EVM runtime tests, independent security review, or live testnet lifecycle validation.
