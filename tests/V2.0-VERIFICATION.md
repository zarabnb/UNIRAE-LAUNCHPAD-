## Important semantics
- `Trade.amountIn` and `amountOut` are raw integer base units. For BUY: native input and token output. For SELL: token input and native output. `feeAmount` is raw native base units.
- The token `verified` flag means discovered through an operator-configured factory event; it does not mean the source code has been audited or independently verified on an explorer.
- Reorg handling replays the previous block and removes affected curve trades/events. Factory cursor rollback also removes orphaned launch records and dependent transfer/trade rows before replay. This remains a bounded per-cursor strategy, not a complete chain-wide reconciliation service.
