# UNIRAE V2.18 — USD graduation calculation correction

## Critical defect corrected

The bonding curve's USD market-cap conversion previously divided by `1e54` after multiplying an 18-decimal native price by an 18-decimal token supply. The correct normalization for those two scaled quantities is `1e36`. The prior expression understated fully diluted market capitalization by `1e18`, so the configured USD graduation threshold could not be reached under ordinary values.

V2.18 first normalizes price × total supply to native-asset value using `WAD * WAD`, then multiplies by the native/USD price normalized to USD-E8. A regression test now asserts the configured initial $500 FDV and the $20,000 graduation FDV at full curve inventory.
