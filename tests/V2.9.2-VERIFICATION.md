# V2.9.2 verification

## Implemented
- Added opt-in Uniswap-V2-compatible pair `Swap` indexer.
- Verifies on-chain token0/token1 match the configured UNIRAE token and quote asset.
- Normalizes buy/sell swap amounts into existing raw-unit trade records.
- Adds timestamps, event provenance, confirmed-block cursoring and orphan-event replay cleanup.
- Added separate worker scripts and operator configuration documentation.
- Candle endpoint reports combined curve + configured V2 pair provenance.

## Checks
- Passed TypeScript transpile-only syntax checks across all 25 backend source files. Passed JSON parsing for package and TypeScript configuration. The legacy V2.8 static checker was not applicable because it hard-codes a V2.8 frontend filename.
- Full TypeScript typecheck, Prisma generation, Vitest, database migrations and live RPC tests require project dependencies and configured infrastructure; they are not claimed as passed.

## Operational safety
No pairs are enabled by default (`DEX_PAIRS_JSON=[]`). Do not enable a pair until its factory, pair address, token addresses, wrapped-native quote token, decimals and start block are independently verified. USD pricing is not implemented. No contracts were deployed and no funds were moved.
